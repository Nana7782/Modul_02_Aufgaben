Aufgabe 1

- Leg einen neuen Request an. 
- Nenne ihn “Star Wars Planeten”. 
- Die URL lautet https://swapi.dev/api/planets 
- Sende den Request ab und schau dir die Antwort an

    - Wie lange hat der Aufruf gedauert?  => 271ms
    - Wieviele Planeten bekommst du als Antwort?  => 60
    - Wie lautet der Name des vorletzten Planeten? => Coruscant (page1), Kalee (page6)
    - Wie ist das Klima (climate) des Planten Hoth? => frozen
- Versuche selbst, die 3. Seite (page=3) aufzurufen.
    - Wie lautet der Name des zweiten Planeten auf dieser Seite? => Corellia

Aufgabe 2

- Leg einen neuen Request an.
- Nenne ihn “Star Wars People”.
- Die URL lautet https://swapi.dev/api/people
- Sende den Request ab und schau dir die Antwort an
    - Wer ist die erste Person in der Antwort? => Luke Skywalker
    - Rufe sein Raumschiff ab - wie heißt es? => x-wing
    - Wie lautet die Haarfarbe und die Augenfarbe der letzten Person aus der Antwort?  => auburn, white/blue-gray
- Rufe die Seite 3 ab.
    - Wer steht dort ganz oben?  => Boba Fett
    - In welchen Filmen kommt die Person vor? => The Empire strikes back, Return of the Jedi, Attack of the Clones
    Suche nach Prinzessin Leia.
Wie man einen Suchtext im Request mitgeben kann, findest du in der [Dokumentation](https://swapi.dev/documentation)
    - Wie groß ist sie? => 150
    - Was ist ihr Heimatplanet? => Alderaan
